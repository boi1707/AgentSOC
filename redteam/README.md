# AgentSOC Red Team & QA

## Purpose

This module contains Red Team and QA resources used to support
controlled security testing and evaluation of AgentSOC.

## Objectives

- Prepare controlled MITRE ATT&CK simulations.
- Build labeled ground-truth datasets.
- Collect available security evidence.
- Evaluate detection performance.
- Maintain reproducible test documentation.

## Scope

- Command Execution
- Privilege Escalation
- C2 Communication
- Exfiltration
- Lateral Movement
