# Red Team Prerequisites

## Available

- Windows VM
- VMware Workstation
- PowerShell
- Atomic Red Team
- Microsoft Sysmon 15.22
- Sysmon Operational Event Log

## Pending Dependencies

- Wazuh integration
- Wazuh Manager
- Snort telemetry
- AgentSOC AI analysis
- Incident management integration

## Rules

- Testing is performed only inside the authorized lab.
- VM snapshots should exist before controlled simulations.
- Missing telemetry must be represented as unavailable.
- Results must not be marked PASS before actual execution.
