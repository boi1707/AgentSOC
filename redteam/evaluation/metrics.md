# Detection Evaluation Metrics

## Precision

Precision = TP / (TP + FP)

## Recall

Recall = TP / (TP + FN)

## False Positive Reduction

FP Reduction =
(Baseline FP - AgentSOC FP) / Baseline FP

## Triage Time

Triage Time =
Incident Decision Time - Initial Detection Time
